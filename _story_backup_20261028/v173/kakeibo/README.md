# かけいぼ（家計簿）

教材アプリの中にある、メニューに出ないページです。
教材アプリの URL の最後に `/kakeibo` を付けて開きます（例：`https://○○.streamlit.app/kakeibo`）。
子どものメニューやトップ画面には出ません。開くときはパスワードが要ります。

## できること

- 入力：日付・支出／収入・金額・カテゴリ・メモ
- 一覧：月ごとの記録と、収入・支出・収支の合計（記録を消すこともできる）
- グラフ：その月の支出のカテゴリ別の内わけ、この1年の収入と支出
- 予算：カテゴリごとの1か月の予算と、残り（オーバーは赤字）
- サブスク：月払い・年払いの登録、1か月あたり・1年あたりの合計。
  支払日が近いと上に知らせる（月払いは7日前、年払いは30日前から）。
  「支払った」を押すと家計簿に記録して、次の支払日へ進む
- 設定：カテゴリの名前と順番

## ファイル

| ファイル | 中身 |
|---|---|
| `kakeibo/app.py` | 画面（タブ6つ） |
| `kakeibo/kb_calc.py` | 計算（合計・予算・サブスクの次の支払日） |
| `kakeibo/kb_store.py` | 保存（Google スプレッドシート。設定がなければ試し用の CSV） |

ページの登録は `common.py` の `build_navigation`（メニューの文字は CSS でかくしている）。

## はじめかた（1回だけ）

1. Google スプレッドシートを1つ新しく作る（名前は何でもOK）。
   右上の「共有」で、教材アプリのサービスアカウントのメールアドレス
   （secrets の `gcp_service_account` の `client_email`）を **編集者** で追加する。
   シート（記録・予算・サブスク・カテゴリ）は、アプリが最初に自動で作ります。
2. Streamlit Cloud の教材アプリの **Settings → Secrets** に、次の2行を足して保存する
   （`[gcp_service_account]` の行より上に書くこと）。

   ```toml
   KAKEIBO_PASSWORD = "家計簿を開くパスワード"
   KAKEIBO_SPREADSHEET_ID = "スプレッドシートのID（URL の /d/ と /edit のあいだ）"
   ```

3. GitHub にプッシュして「Reboot app」。`…streamlit.app/kakeibo` を開く。

※ secrets を足す前は「試し用の保存」で動きます（再起動で消えます）。

## 画面について（2026-11 から）
- 画面はすべて `ui/index.html`（JavaScript）。`app.py` はデータを渡して、操作を保存するだけです。
- Streamlit Cloud の右下のアイコンや上のバーは、アプリの外側に表示されるため消せないことがあります。
  そのときは URL の「.streamlit.app/」のあとに「~/+/」を入れて開いてください（例：`https://〇〇.streamlit.app/~/+/kakeibo`）。
  スマホのホーム画面には、この URL で追加するのがおすすめです。
