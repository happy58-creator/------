# 買い物リスト

家計簿と同じく、教材アプリの中の「メニューに出ないページ」です。URL の最後を `/kaimono` にすると開きます
（例：`https://〇〇.streamlit.app/~/+/kaimono`）。別に公開する必要はありません。

- 画面：Vue（JavaScript のフレームワーク）… `ui/`（`ui/vendor/` に Vue と地図の Leaflet）
- 裏側：Python … `app.py`（保存は家計簿の `kakeibo/kb_store.py`）
- ログイン：家計簿と共通（`kakeibo/kb_auth.py`）。家計簿で入っていれば、そのまま入れます。24時間つづきます。
- 保存先：家計簿と同じ Google スプレッドシートに「買い物」「店舗」「支店」「買い物ジャンル」などのシートが自動でできます。
- お店（例：無印良品）の中に店舗（例：イオンモール福岡店・かやの森店）をいくつも登録できます。買うものがあるお店の、未登録の店舗の近くに行くと「登録しますか？」と出ます。

画面は「入力・一覧・店舗別・計算・メニュー」。家計簿のメニューの「買い物リスト」と、買い物リストのメニューの「家計簿へ」で行き来できます。

現在地を使うので、ホーム画面に置くときは `~/+/kaimono` の形の URL がおすすめです（Streamlit の外枠の中だと、位置情報が使えないことがあります）。
