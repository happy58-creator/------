## 問題のルール
- choices に「ア」「イ」などの記号をつけない（画面で付ける）。answer は 0 始まりの番号。why は choices と同じ数。
- 科目A：選択肢はちょうど4つ。科目B：本番と同じく 4〜10個（空欄の組合せ問題は6〜8個が多い）。
- 正解の位置を偏らせない（バッチ内でほぼ均等に）。正解はちょうど1つ。「すべて正しい」系は使わない。
- level：1=基本、2=標準、3=難（計算・複合）。科目Aの目安 2:5:3。
- 事実の正確さ最優先。法律・制度・最新用語は WebSearch で確認してよい（例：下請法は2026年1月から「中小受託取引適正化法（取適法）」）。
- **計算・トレースは必ず python3 で検算する。擬似言語はPythonに書き直して実行し、答えを確かめる。**
- HTML の都合で、問題文・コード中の不等号は全角（＜ ＞ ≦ ≧ ≠）で書く。半角の < > は使わない（タグだけに使う）。

## 擬似言語（IPA の記述形式に合わせる）
```
○整数型: 関数名(整数型: n)        ← 手続・関数の宣言
整数型: i, k ← 0                    ← 変数の宣言と初期化
整数型の配列: data ← {3, 1, 2}      ← 配列（要素番号は1から。要素数は「dataの要素数」）
/* 注釈 */
if (条件式) … elseif (条件式) … else … endif
while (条件式) … endwhile
do … while (条件式)
for (i を 1 から n まで 1 ずつ増やす) … endfor
return 式
演算子：＋ − × ÷（整数の商） mod（剰余） and or not ＝ ≠ ＜ ≦ ＞ ≧ ← 、未定義の値は「未定義」
クラス・リストは「ListElement型: p」「p.next」「p.val」など、問題文の中で説明してから使う。
```
科目Bの問題文は本番どおり「次の記述中の［　a　］に入れる正しい答えを，解答群の中から選べ。」「次のプログラム中の a と b に入れる正しい答えの組合せを…」の形。プログラムの説明→プログラム（<pre>）→設問の順。
