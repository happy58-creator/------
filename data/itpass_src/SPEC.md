# ITパスポート学習教材 — 生成仕様（全バッチ共通）

対象：ITパスポート試験（IPA）。シラバス **Ver.6.5（2026年1月掲載・最新）** に準拠。受験者は社会人の初学者（本人が自分用に勉強する）。
本番形式：CBT・四肢択一 100問／120分。分野別出題目安 ストラテジ系35問・マネジメント系20問・テクノロジ系45問。
合格基準：総合評価点 600点以上（1000点満点）かつ 各分野の評価点 300点以上。

## 著作権
- IPAの過去問の文章をそのまま写さないこと。すべてオリジナルの問題文・選択肢・解説を書く（本番と同じ「形式・難易度・出題テーマ」に寄せるのはOK）。

## 問題のルール（大事）
- choices に「ア」「イ」などの記号はつけない（画面で ア〜エ をつける）。answer は 0〜3 の番号。
- **正解の位置を偏らせない**：そのバッチの answer が 0/1/2/3 でほぼ同数になるようにする。
- 正解はちょうど1つ。紛らわしい誤答（本番らしい「もっともらしい誤り」）を3つ。「すべて正しい」「どれでもない」は使わない。
- level：1=基本用語、2=標準（本番の大半）、3=やや難（計算・事例・組合せ）。割合の目安 1:2:3 = 3:5:2。
- 本番によく出る形を混ぜる：用語の定義、事例「〜に該当するものはどれか」、計算（損益分岐点・利益・稼働率・データ量・2進数など）、組合せ（a〜dの記述のうち適切なものの組合せ）、図表・擬似言語。
- 事実の正確さ最優先。迷う内容（法改正・数値・新しい用語）は WebSearch で確かめてから書く。古い制度名を正解にしない。
- id は「cat-3桁連番」。topic はそのバッチ内で偏らないよう、シラバスの小分類・重要用語を広くカバーする。
- 解説は初学者向けにやさしく、でも正確に。why は4つ（選択肢と同じ順）。

## 解説（lessons）のルール
- 各 cat に1つ。sections は4〜8個。シラバスの重要用語を網羅し、本番で問われる観点（定義・違い・計算方法・ひっかけ）を中心に。
- 計算がある分野は、例題と解き方を入れる。似た用語は表で比べる。

## 用語（terms）のルール
- 各 cat につき 12〜25 語。本番頻出の用語を優先。def は 50〜120字。

## 文体
- です・ます調。問題文は本番どおり「〜はどれか。」。
